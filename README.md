# Cloud Infrastructure Threat Investigation

## Overview

A network forensics investigation of a compromised cloud infrastructure environment using PCAP analysis. The investigation focused on identifying attacker activity, tracing unauthorized access to OpenStack services, analyzing sensitive data access, and reconstructing the attack timeline.

## Tools & Technologies

* Wireshark
* PCAP Analysis
* OpenStack
* HTTP Traffic Analysis
* MITRE ATT&CK

## Key Findings

* Identified attacker reconnaissance using **ffuf**
* Investigated unauthorized dashboard access
* Traced attacker interactions with **OpenStack Keystone and Swift**
* Identified access to sensitive user data
* Detected creation of a privileged account for persistence
* Mapped attacker behavior to **MITRE ATT&CK T1136.001**
